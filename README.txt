แอปคำนวนน้ำโดรนพ่นยาทุเรียน
================================

ไฟล์ในชุดนี้:
- index.html: ตัวแอป
- manifest.webmanifest และ icon.svg: ข้อมูลติดตั้งและไอคอน
- sw.js: แคชไฟล์เพื่อเปิดใช้งานออฟไลน์หลังเข้าครั้งแรก

วิธีใช้งานทันที:
1. แตกไฟล์ ZIP
2. เปิด index.html ด้วยเว็บเบราว์เซอร์บนคอมพิวเตอร์เพื่อทดลองใช้งาน

วิธีทำเป็นแอปติดตั้งบน iPhone และ Android:
1. นำไฟล์ทั้งหมดในโฟลเดอร์นี้ไปเผยแพร่บนเว็บโฮสติ้งที่รองรับ HTTPS (เช่น GitHub Pages หรือบริการ static hosting)
2. เปิด URL ของเว็บที่เผยแพร่แล้วบน iPhone ด้วย Safari หรือบน Android ด้วย Chrome
3. iPhone: กด Share > Add to Home Screen
   Android: เปิดเมนู Chrome > Install app หรือ Add to Home screen

หมายเหตุ:
- ชุดนี้เป็น Progressive Web App (PWA) ใช้ได้ทั้ง iPhone และ Android ไม่ใช่แอปที่เผยแพร่ใน App Store/Play Store
- ประวัติถูกเก็บใน localStorage ของเบราว์เซอร์/อุปกรณ์นั้น ไม่ได้ซิงก์ข้ามเครื่อง
- การคำนวณสมมติว่าพ่นต่อเนื่องตลอดระยะทาง ไม่รวมการเลี้ยว หยุดพ่น หรือการเดินทางไปกลับ
